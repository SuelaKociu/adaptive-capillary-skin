# Physical experiment records

Do not place simulated data here. This directory is reserved for future **measured** results.

For each physical run, create a directory such as:

```text
experiments/2026-XX-XX_specimen-ACS001/
  specimen_metadata.json
  raw_flow.csv
  raw_pressure.csv
  images/
  video/
  calibration/
  deviations.md
  analysis.py
```

Use the templates in `templates/` and preserve failed runs.
