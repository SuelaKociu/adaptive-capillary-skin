# Human–AI provenance record

This directory documents the research process rather than treating the final artifact as if it appeared in one step.

## Current evidence level

`curated_trace_2026-08-19.md` is a human-readable reconstruction from the working conversation. It is **not a cryptographically complete raw chat export**. For formal research on collaborative cognition, the original exported conversation should be preserved separately with timestamps and platform metadata where permitted.

## Attribution principle

The project distinguishes:

- human analogy, goals, selections and redirects;
- AI-assisted expansion, formalization, code, simulations, critique and drafting;
- joint revisions that only emerged after reciprocal turns.

The purpose is transparency, not anthropomorphic authorship. The AI system is disclosed as a tool/participant in the workflow but is not a legal or scientific author.
