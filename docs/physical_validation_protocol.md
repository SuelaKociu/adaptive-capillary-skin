# Physical validation protocol — staged V1

**Purpose:** test the core hydraulic self-isolation mechanism before attempting a fully miniaturized multifunctional skin.

## Stage 0 — transparent mesoscale hydraulic demonstrator

Build a transparent network large enough to image directly. The aim is not biological scale; it is causal validation.

### Minimum layout

- one inlet manifold;
- at least two redundant paths between inlet and outlet;
- one deliberately vulnerable central branch;
- interchangeable isolation collar around that branch;
- matched control branch without active swelling material;
- calibrated puncture/leak port;
- upstream and downstream pressure measurement where available;
- mass or volumetric measurement of useful outlet and leak flow.

### Candidate benign working fluid

Water with a visible inert dye may be used for early hydraulic visualization. Any additives must be documented because viscosity, conductivity and surface interactions alter the model.

## Experimental sequence

1. Prime network and verify stable pre-damage flow.
2. Record baseline useful outlet flow for a fixed interval.
3. Introduce a controlled damage/leak of known geometry at `t = 0`.
4. Record leak flow, useful outlet flow and local images continuously.
5. Continue until either isolation plateaus or the preregistered time limit is reached.
6. Repeat with an identical hydrogel-free control.
7. Repeat across independent specimens; do not count repeated runs on one specimen as independent specimens.

## Primary endpoints

- peak leak flow;
- leak flow at late time;
- percent leak reduction;
- time to 80% reduction from peak;
- useful outlet-flow retention;
- failure mode.

## Secondary stages

Only after Stage 0 succeeds should the project add:

- microfluidic down-scaling;
- hygromorphic gating;
- real electrokinetic transduction;
- evaporative cooling measurements;
- fog/dew capture;
- fatigue and contamination testing.

A multifunctional prototype should not be used to hide failure of the core mechanism.
