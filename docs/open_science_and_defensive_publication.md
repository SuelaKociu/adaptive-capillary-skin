# Open science and defensive-publication intent

The project is designed to be inspectable, reproducible and citable. Public release includes enough technical detail to invite criticism and independent implementation attempts.

The project uses the phrase **defensive-publication intent** descriptively: the author is choosing public disclosure rather than secrecy for this version. Whether a particular public record qualifies as prior art against a later patent claim depends on jurisdiction, dates, claim language and legal analysis. No repository file should state that publication *guarantees* that another party cannot obtain any patent involving related technology.

Versioned public releases, persistent archival records and a DOI are recommended for provenance. GitHub is used for living code and collaboration; Zenodo or another archival repository should be used for an immutable citable release record.
